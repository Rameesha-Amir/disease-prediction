A machine learning project that estimates a student's depression risk using 
real survey data on academic life, lifestyle, and demographics (Kaggle's 
Student Mental Health dataset). Built with a Random Forest classifier trained 
on features like course, year of study, CGPA, marital status, and anxiety 
history. Includes a full pipeline (preprocessing, feature engineering, 
training, evaluation) and a live web interface called "MindCheck" — built 
with Flask, HTML, CSS, and JavaScript — where users can fill a short form 
and see a real-time risk indicator.

Tech stack: Python, scikit-learn, pandas, Flask
Model performance: 80% accuracy, 0.71 ROC-AUC
